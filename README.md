# Sales Data Visualization
**Author:** AYUSH RAJPUT  
**Track:** AI & ML — Level 1, Day 26

## Project Overview
This beginner-friendly project uses Python, Pandas, and Matplotlib to visualize sales data through a bar chart and a line chart. It highlights category-wise sales performance and monthly sales trends.

## Requirements
- Python 3.9+
- pandas
- matplotlib
- jupyter (optional, for the notebook)

## Setup
```bash
pip install -r requirements.txt
python sales_visualization.py
```
The script saves charts in the `outputs/` folder and prints observations in the terminal.

## Files
- `sales_visualization.py` — complete runnable project
- `data/sales_data.csv` — sample dataset
- `notebooks/sales_visualization.ipynb` — notebook version
- `outputs/` — generated charts after running the script
- `requirements.txt` — dependencies
